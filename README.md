# C#

A collection of C# Windows Forms projects from competitions and practice.

## Contents

| Folder | What it is |
| --- | --- |
| `OJTI 2018`, `OJTI 2019`, `OJTI 2022`, `OJTI 2022 - V2`, `OJTI 2023` | Projects for the county stage of the Romanian IT olympiad (OJTI) |
| `ONTI 2018`, `ONTI 2019`, `ONTI 2019 - V2`, `ONTI 2022`, `ONTI 2022 - V2`, `ONTI 2023`, `ONTI 2023 - V2`, `ONTI 2024` | Projects for the national stage (ONTI) |
| `GraphicsTest` | A small experiment that draws triangles with GDI+ lines in a picture box |
| `JustTests` | A menu form that opens six test forms, backed by a local SQL Server database |

## Run

These projects need Windows and Visual Studio. Open the `.sln` file in a folder and press F5.
